# 5단계 — 안드로이드 프로젝트 골격 + 지도 위 선 그리기 화면

`지장이설관리/android/`에 새 안드로이드 프로젝트를 생성하고, 4단계 데이터
모델을 Room DB로 구현한 뒤, 로드맵 5단계 본론인 **"GIS 캡처 이미지 위에
케이블 경로 선을 그리고 편집하는 화면"** 까지 완성했다.

## 구성
- 패키지: `com.thkim.jijang`
- 골프 앱과 동일한 Gradle/Kotlin 버전 (AGP 8.5.2, Kotlin 1.9.24)
- **지도 SDK 미사용** — 실제 시설물 위치는 사내 GIS에만 있으므로, 담당자가
  GIS 화면을 캡처한 이미지를 앱에서 불러와 배경으로 쓰는 방식으로 결정
  (Google Maps 의존성 제거, API 키 이슈도 자연히 해소됨)
- 로컬 DB: Room 2.6.1, 엔티티 14개 (`BaseMapImage` 추가)

## 화면 구성 (이번 단계에서 추가)
1. **현장 목록** (`MainActivity`) → 항목 클릭 시 상세 화면 이동
2. **현장 상세** (`CaseDetailActivity`) → "개황도(전)/개황도(후) 편집" 버튼
3. **경로 편집** (`DiagramEditActivity` + `RouteEditorView`)
   - "이미지 불러오기" 버튼으로 갤러리에서 GIS 캡처 이미지 선택 → 앱 내부
     저장소에 복사 → `BaseMapImage`로 저장
   - 이미지 위에서 **빈 곳 탭 = 점 추가**, **점 드래그 = 이동**,
     **점 길게 누르기 = 삭제**
   - 점은 이미지 기준 상대좌표(0~1)로 저장되므로 화면 회전/기기 변경과
     무관하게 항상 정확한 위치 유지
   - "저장" 버튼으로 `RouteLine`/`RoutePoint`에 반영

> MVP 범위에서는 이미지 1장당 선을 1개만 지원한다 (신설/철거 등 여러 선을
> 색으로 구분해 관리하는 기능은 다중 선 UI가 필요해 후속 확장으로 분리).

## 빌드 검증
```
./gradlew :app:assembleDebug
BUILD SUCCESSFUL
```
전체 소스(Room 엔티티/DAO, 커스텀 View, 액티비티 3개) 포함해서 컴파일·
리소스 병합·APK 패키징까지 통과 확인.

## 부수적으로 발견/수정한 이슈
- 기존 골프 앱(`android/gradlew`)의 CLASSPATH 라인이 깨져 있어 커맨드라인
  빌드가 실패하는 상태였음 (Android Studio로만 빌드되어 온 것으로 보임).
  새 프로젝트의 `gradlew`는 정상 값으로 고쳐서 사용 중. **골프 앱 쪽은
  아직 안 고쳤음 — 필요하면 동일하게 고쳐드릴 수 있음.**

## 아직 안 한 것 (다음 단계에서 진행)
- 체크리스트/사진 입력 폼 (6단계)
- 단가표 업로드 파서 (7단계)
- 엑셀 생성 엔진 (9단계) — 배경 이미지+선 합성 비트맵 렌더링, Apache POI로
  템플릿 셀에 데이터/이미지 삽입. Apache POI를 안드로이드에서 쓰는 부분은
  라이브러리 크기·호환성 이슈가 있어 별도 검증 필요 (위험 요소로 기록)
- 다중 선(신설/철거 구분) 지원
- 사진 촬영(카메라) 연동 — 매니페스트에 CAMERA 권한은 미리 추가해둠
