# 11단계 — `기별` 시트 내보내기 (원가계산 자동화 연결)

10단계에서 입력받은 구간(`RouteSegment`) 목록을 실제 `기별` 시트에 채워 넣는다.
`기별`을 채우면 07단계에서 이미 확인한 `내역서_일반`/`자재내역서_일반`의
SUMPRODUCT 수식이 그 값을 그대로 집계하므로, **엑셀을 열기만 하면 원가계산까지
자동으로 이어진다** — 이게 이 앱의 최종 목표("입력하면 정산 엑셀이 자동으로
나온다")의 핵심 연결고리다.

## 구성

- **`GibyeolSheetComposer`** (`data/excel`) — 구간 목록을 11행부터 한 구간당
  한 행으로 채운다. 실제 파일을 직접 열어 각 열이 수식인지 순수 입력 셀인지
  확인한 결과:
  - **D/H/I/AJ/AB/AC/AD/AE/AF/BD/BF/BG/BH/AI 열은 전부 빈 입력 셀** — 그대로
    값을 써넣는다.
  - **AH열만 `=IF(AE11<>"",H11,0)` 수식이 미리 들어있다** — 그래서 AH는
    절대 건드리지 않는다. H/AE만 정확히 채우면 엑셀이 열릴 때 자동으로
    재계산되어 AH도 올바른 값이 된다 (9단계에서 이미 워크북에
    `fullCalcOnLoad="1"`을 켜둔 이유가 바로 이거다).
  - 누적거리(I열, AJ열 — 원본에 같은 의미가 두 번 들어있다)는 사용자에게
    입력받지 않고, 구간 순서(seq)대로 구간거리를 누적 합산해서 계산한다.
  - G열("시설물 구분": 기타/건물 등)은 지금 입력 화면에 없는 항목이라 비워둔다.
- **`XlsxExporter`**에 `기별` 시트 패치를 추가 — 9단계에서 만든
  `XlsxCellPatcher`/`XlsxReader.sheetEntryPath`를 그대로 재사용했다 (새 인프라
  없음). `엑셀 내보내기` 버튼 한 번으로 ENG시트 + 사진 + 기별이 한꺼번에
  채워진 파일이 나온다.

## 실제 파일로 검증한 것

원본 `기별!sheet20.xml`을 직접 패치해보고 SAX로 재파싱해서 확인했다:
- D/H/I/AB/AC/AD/AE/AF/AJ/BD/BF/BG/BH 셀에 값이 정확히 들어갔다.
- **AH11의 `<f t="shared" ref="AH11:AH74" si="6">IF(AE11<>"",H11,0)</f>` 수식이
  손상 없이 그대로 남아있음을 확인했다** (패치 후에도 `<f>` 태그 존재 검증).
- 패치 후 파일이 여전히 올바른 XML임을 SAX 파서로 재확인했다 (파싱 에러 없음).

이번에도 마찬가지로 이 한 건의 실제 파일로만 검증했다 — 실제 업무 PC에서 이번
내보내기 결과물을 열어 `내역서_일반`의 수량이 기대한 대로 집계되는지 최종
확인이 필요하다 (AH11 캐시값이 패치 직후엔 구식(0)이지만, 엑셀에서 파일을
열면 fullCalcOnLoad 때문에 자동으로 60으로 재계산되는 것까지 앱 밖에서 직접
확인은 못 했다 — SAX 재파싱으로는 "수식이 안 깨졌다"까지만 확인 가능).

## 아직 남은 것
- 실제 엑셀 프로그램으로 내보내기 결과물을 열어서 원가계산서까지 정상
  집계되는지 최종 확인 (AI열 "여장", G열 "시설물 구분" 등 지금 입력 화면에
  없는 항목은 항상 비워짐 — 필요해지면 10단계 입력 화면에 필드 추가)
- 개황도(전/후) 배경 이미지 위에 그린 선을 합성해서 `개황도` 시트에 삽입하는
  기능 (5단계에서 좌표 데이터는 이미 저장 중이지만 아직 엑셀에는 안 채움)
- 다중 선(신설/철거 구분), 안전관리비 조건부 할증 등 나머지 세부 항목
