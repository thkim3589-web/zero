기준 시안: `디자인시안_v3.html` (밝은 배경 + 큰 라운드 카드, 파랑 기본 / 주황 핵심 동작 / 초록 완료).

## 추후 변경될 가능성이 큰 요소

### A. 시안에는 있으나 앱에 아직 없는 기능 (결정 필요)
1. **현장 목록 상태 필터 탭** (전체/작성중/제출/완료) — `MainActivity` + DAO 쿼리 필요.
2. **현장 조사 화면의 GPS 자동 입력 / 지장물 아이콘 선택(관로·수목·건물·전주)** — 현재 ENG 체크리스트 폼 구조와 충돌 여부 확인 필요. 위치 권한도 추가됨.
3. **예산 산출 도넛 차트** — 공량 화면에 노무/자재/장비 비율. 단가 마스터에서 계산 가능하나 분류 기준 확정 필요.
4. **PDF 출력 / 공유** — 지금은 엑셀(xlsx) 내보내기만 있음. 시안의 "PDF", "공유" 버튼은 임시 요소.
5. **알림(벨) 아이콘** — 시안 상단에 있으나 앱에 알림 개념이 없음. 넣지 않는 것을 권장.

### B. 코드에 박혀 있는 색 (토큰만 바꿔서는 안 바뀜)
- `FormBuilder.kt:99,193`, `DiagramEditActivity.kt:316` — `#F5F7F9` 외곽선 색 (`surface_muted`로 이전 권장)
- `DiagramEditActivity.kt:354`, `DiagramCompositor.kt:61` — `#B7C0CC` 테두리/격자
- `RouteEditorView.kt:91,201` — 기본 선 색 `#FF3B30`. **시안 v3의 "기존=파랑 실선 / 이설=주황 점선"과 다름.** 개황도 기본 색을 바꿀지 결정 필요
- 개황도 선 색(`colorHex`)은 **DB에 저장된 사용자 값**이라 디자인 개편으로 일괄 변경하면 안 됨. 엑셀 합성(`DiagramCompositor`)과 화면 색이 같아야 한다.
- `FormBuilder.kt:35` 섹션 번호 배지 색 6개 — 새 팔레트에서 파랑·주황·초록이 겹쳐 보일 수 있어 눈으로 확인 필요
- `CaseDetailActivity.kt:65~69` 메뉴 배지 색 (`badge_teal`은 이제 초록)

### C. 화면별로 아직 시안 레이아웃이 아닌 곳
- 현장 상세: 시안의 "6단계 진행률 + 단계 목록" 구조가 아니라 기존 메뉴 카드 목록 (v2 시안 아이디어, 필요하면 적용)
- 툴바: 지금은 파란 단색 바. 시안의 "밝은 배경 + 큰 제목" 헤더로 바꾸면 모든 화면 레이아웃(약 10개) 수정 필요
- 하단 고정 액션 바: 시안은 모든 화면에 두지만 앱은 화면마다 버튼 위치가 제각각
- 아이콘 `ic_menu_*`는 흰색 선 고정 — 배경이 밝은 헤더로 바뀌면 `tint` 방식으로 변경해야 함
- `ic_input_add`는 안드로이드 기본 아이콘 (자체 아이콘으로 교체 권장)

### D. 기타
- 다크 모드: 테마가 `DayNight`이나 `values-night`가 없어 시스템 다크 모드에서 일부 흰/검정이 어긋날 수 있음. 라이트 고정(`AppCompatDelegate`) 여부 결정 필요.
- 글꼴: 시안은 Noto Sans KR. 앱은 시스템 글꼴 → 기기별로 느낌이 다름. 폰트 번들 시 APK 용량 증가.
- 문구: FAB "새 현장 추가", 상태 라벨 "작성중/제출됨/내보내기 완료"는 `StatusChip.kt`에 하드코딩 — 문구 바뀌면 strings로 이전.

## 3차 진행 — 디자인 v4 적용 (0.4.0)
참고 웹앱(슬레이트 헤더 + 블루 포인트)을 기준으로 `디자인시안_v4.html`을 만들고 토큰을 교체했다.
- 팔레트: primary `#0F172A`(헤더/구조), accent `#2563EB`(핵심 동작), 상태 칩 앰버/블루/그린, 배경 `#F1F5F9`
- 모서리: 카드 12dp, 입력칸 9dp, 버튼 10dp / 높이 48dp
- 필터 칩 선택색을 accent로, 체크리스트 섹션 배지 6색 중 겹치던 초록 하나를 앰버(`badge_amber`)로 교체
- v3(0.3.x)의 파랑·주황 팔레트는 폐기. 개황도 선 기본색(`#FF3B30`)은 사용자 저장값과 연결되어 변경하지 않음
- 시안의 4탭 구조(현장조사·도면·물량·현황)와 KPI/칸반은 앱에 아직 미적용(화면 구조 변경 필요)

## 4차 진행 — 현장 상세 4탭 구조 (0.5.0)
시안 v4의 4탭 구조를 현장 상세 화면에 네이티브로 적용했다.
- 탭: 현장조사(체크리스트·사진) / 도면(구간·개황도 전/후) / 물량(원가계산 수량) / 현황(진행 요약 + 엑셀 내보내기)
- 같은 화면에서 카드 묶음의 표시만 전환(`CaseDetailActivity.setupTabs`), 마지막 탭은 회전 시 유지
- 카드 부제목과 현황 요약은 `onResume`마다 DB(사진/구간/수량/개황도)에서 다시 읽는다
- 미적용: 목록 화면의 칸반/KPI, 금액 합계(단가 마스터 조인 필요), GPS 자동 입력, 지장물 종류 선택

## 5차 진행 — 개황도 편집기 정밀도 개선 1단계 (0.5.1)
- 점/선/글자 크기를 "화면에서 보이는 크기"로 고정: 확대해도 커지지 않아 정밀하게 찍을 수 있다 (`pointRadiusPx`, onDraw에서 배율로 나눔)
- 점 터치 판정을 반지름 24dp로 확대, 배율에 맞춰 보정 (`hitRadiusPx`). 드래그 임계값도 화면 좌표 기준으로 변경
- 점을 끌 때 손가락 위쪽 52dp에 점을 띄우고(조준) 안내선·십자 조준선 표시. "조준 ON/OFF" 토글
- 되돌리기/다시 (점 추가·이동·삭제·종류변경 단위, 최대 60단계). 선을 바꾸거나 다시 불러오면 기록 초기화
- 후속(2~3단계): 선 위 탭으로 점 삽입, 스냅/직각 맞춤, 속성 하단 시트, 구간 길이(축척) 표시

## 6차 진행 — 개황도 범례 선/도형 심볼 적용 (0.6.0)
SKT 개황도 범례(선 17종, 도형 심볼 25종)를 개황도를 그릴 때 그대로 고르게 했다.
- 카탈로그: `legend/Legend.kt` (`LegendCatalog.lines/symbols`, `LegendDraw`). 화면·선택창·엑셀 합성이 같은 그리기 코드를 쓴다
  - 선: 가공/지중/FTTH/T·B공동 신설(점선)·기설(실선), 케이블 철거, SKB, 임차(일점쇄선), 단순이설(케이블/화살표), 자가·타사 관로
  - 심볼: 함체 P / Master M / Slave S (신설·기설·철거), SKB함체, 전주 C (자가·한전·타사), 국사/기지국/중계기, 맨홀(자가·타사)
- DB 8→9: `route_line.styleId`, `route_point.symbolId` (기존 데이터는 null로 그대로 유지, 예전 방식으로 그려짐)
- 화면: "선 종류" 버튼(편집 중인 선의 색/패턴/이름 일괄 변경), "도형 심볼" 버튼(고른 뒤 지도를 탭하면 즉시 배치), 점 탭 메뉴의 "범례 심볼로 변경", "+ 선 추가"에서 범례로 선택
- 엑셀 합성(`DiagramCompositor`)도 범례 선 패턴·심볼을 그대로 그린다
- 미적용: 사용한 항목만 모아 범례 표를 자동 생성하는 기능(C단계), 국사/기지국/중계기 아이콘의 정확한 형상(현재는 글자 사각형)

## 7차 진행 — 범례 표 자동 생성 (0.6.1)
- 범례 이미지를 올리지 않은 개황도는 엑셀 내보내기 때 **실제로 쓴 선 종류·도형 심볼만** 모은 "범 례" 표를 우하단에 자동으로 그린다 (`DiagramCompositor.drawAutoLegend`). 올린 범례 이미지가 있으면 기존대로 그 이미지를 쓴다.
- 빌드(`assembleDebug`) 통과. 내보낸 엑셀의 실제 화면 확인은 아직 못 했다.
- 남은 것: 국사/기지국/중계기 아이콘 정확한 형상, 개황도 정밀도 2~3단계(선 위 탭 삽입, 스냅/직각, 구간 길이 표시).
