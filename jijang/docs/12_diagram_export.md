# 12단계 — 개황도(전/후) 합성 이미지 내보내기

5단계에서 만든 개황도 편집 화면(GIS 캡처 이미지 + 경로 점 목록)을 실제
`개황도(전)`/`개황도(후)` 시트에 이미지로 삽입한다. 9~11단계에서 다룬 텍스트
셀 채우기와 달리, 이번엔 그림(그리기 개체) 삽입이라 별도 처리가 필요했다.

## 실제 파일로 확인한 것

- 배경 이미지 앵커는 실제로 **정확히 `col 0~35, row 20~89`** (0-indexed)에
  있었다 — 3단계 문서의 "실측" 메모가 정확했음을 재확인.
- 이 앵커 하나만 유난히 크고(전체 캔버스 크기), 나머지 ~200개 앵커는 전부
  1~2셀짜리 범례 아이콘/도형(케이블 경로 도형 등)이었다. 그래서 "정확히
  `col=0,row=20`에서 시작하는 앵커"만 찾아서 그 하나만 제거하고 나머지는
  손대지 않는 방식이 안전하게 통했다 (실제 파일로 검증: 205개 → 204개, 나머지
  204개는 그대로).

## 구성

- **`DiagramCompositor`** (`data/excel`) — 배경 비트맵 위에 저장된 경로 점을
  선+점으로 그려서 합성 비트맵을 만든다. `RouteEditorView`의 화면 그리기와
  같은 스타일이지만, 뷰가 아니라 이미지 원본 해상도에 직접 그리므로 letterbox
  계산이 필요 없다 (상대좌표 0.0~1.0을 이미지 너비/높이에 곱하기만 하면 됨).
- **`XlsxDrawingPatcher.removeAnchorMatchingFrom`** — `from` 좌표가 정확히
  일치하는 `twoCellAnchor` 하나만 찾아서 제거하는 함수 추가.
- **`XlsxExporter`** — 개황도(전)/개황도(후) 각각에 대해: 저장된
  `BaseMapImage`가 있으면 배경+경로를 합성 → 기존 배경 앵커 제거 → 같은
  좌표에 새 이미지로 교체. 저장된 배경 이미지가 없는 현장(개황도 편집을 아직
  안 한 경우)은 조용히 건너뛴다.
- 사진 삽입(9단계)과 개황도 삽입이 이제 **같은 drawing 파트에 여러 장을
  순서대로 추가하는 공용 로직**(`addImageAnchor`)을 공유하도록
  `XlsxExporter`를 정리했다 — media 파일 번호/관계 ID가 겹치지 않게 전체
  내보내기 과정에서 하나의 카운터로 관리한다.

## 실제 파일로 검증한 것

원본 `개황도(전)` 시트의 drawing 파트를 직접 패치해보고:
- 배경 앵커(`col=0,row=20`) 정확히 1개만 제거됐고 나머지 204개(범례/도형)는
  그대로 남았다.
- 제거 후 새 앵커를 추가해서 원래와 같은 앵커 개수(205개)로 복원되는지 확인.
- 패치 후 파일이 SAX 파서로 문제없이 재파싱되는지 확인 (well-formed).
