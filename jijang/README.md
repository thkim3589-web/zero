# 지장이설관리 (Jijang)

현장(불량함체 개선 등 지장이설)에서 모바일로 입력한 데이터를 SKT 표준 정산 엑셀 템플릿 형식으로 자동 생성하는 안드로이드 앱 (Kotlin, Room, minSdk 26).

## 구현된 기능
- 현장 건(SiteCase) 목록/상세 관리
- ENG시트 체크리스트 입력 (아코디언 폼)
- 현장 사진 촬영/첨부 (3x N 슬롯, 엑셀 사진시트 대응)
- 개황도(전/후) 편집기: GIS 캡처 이미지 위에 상대좌표(0~1) 벡터로 경로 작성, 다중 선, 핀치줌/팬, 점 탭 액션 메뉴, 색상/선종류/범례 도형
- 구간(기별) 입력, 공량(작업수량) 입력
- 단가 마스터 엑셀 업로드/파싱 (SKT 단가 개정 시 갱신)
- 엑셀 내보내기 (온디바이스 xlsx 패치: ENG, 기별, 사진, 개황도 합성)
- Room DB (스키마 v8, 마이그레이션 포함)

## 구조
- `android/` : 앱 소스 (패키지 `com.thkim.jijang`)
- `docs/` : 단계별 설계 문서 (01 요구사항 ~ 15 디자인 개편)
- `android/docs/` : 16 개황도 편집기 개편, 17 다중 선, 18 전체 감사 및 버그 수정

## 최근 진행
- 16단계: 개황도 편집기 전면 개편 + DB 마이그레이션
- 17단계: 선 개수 제한 해제 (N개)
- 18단계: 코드 감사 — 이미지 재선택 시 선 삭제 버그, 사진 슬롯 중복 버그 수정

## 빌드
`android/local.properties`에 `sdk.dir` 설정 후 `./gradlew assembleDebug`
