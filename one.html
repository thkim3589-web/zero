텍스트 인식 엔진

기본은 무료 오프라인 엔진(Tesseract)이에요. 정확도를 높이려면 구글 클라우드 Vision API 키를 입력하세요 — 입력하면 앞으로 촬영/업로드 시 자동으로 Vision API를 우선 사용하고, 실패하거나 키가 없으면 기본 엔진으로 인식합니다. 이 기기에만 적용되니, 팀원마다 각자 자기 휴대폰에 본인 키를 넣어서 따로 쓰면 됩니다.

Google Cloud Vision API 키

월 1,000장까지 무료(사람별로 각각 적용), 이후 1,000장당 약 1.5달러가 청구돼요. 무료 한도 내에서만 써도 구글 클라우드 계정에 결제수단 등록은 필요합니다. 키는 이 기기의 브라우저에만 저장되고 서버로 전송되지 않아요.

  1. Google Cloud Console에 구글 계정으로 로그인 → 새 프로젝트 만들기 (이름 아무거나, 예: 현장문서인식)
  2. 만든 프로젝트를 선택한 상태에서 Cloud Vision API 페이지로 이동 → "사용 설정" 버튼 클릭
  3. 결제 계정 연결 안내가 뜨면 카드 등록 (월 1,000장 이내는 요금 청구 안 됨)
  4. 좌측 메뉴 "API 및 서비스" → "사용자 인증 정보" → 상단 "+ 사용자 인증 정보 만들기" → "API 키" 선택
  5. 생성된 키를 복사해서 위 입력칸에 붙여넣고 저장
  6. (보안 권장) 방금 만든 키를 눌러 편집 → "API 제한사항"에서 "Cloud Vision API"만 체크 → "애플리케이션 제한사항"에서 "HTTP 리퍼러"를 선택하고 본인 앱 주소(예: https://아이디.github.io/*) 등록 → 저장. 이렇게 하면 키가 유출돼도 이 앱 용도로만 쓰이도록 제한됩니다.
